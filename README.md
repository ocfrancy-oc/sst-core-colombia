# 🛡️ SST-Core Colombia: Automatización del SG-SST

**Solución SaaS para el cumplimiento normativo de la Resolución 0312 de 2019 y el Decreto 1072 de 2015 en PyMEs colombianas.**

## 🚀 Propuesta de Valor
SST-Core elimina la carga administrativa del Sistema de Gestión de Seguridad y Salud en el Trabajo mediante un motor de reglas que automatiza:
*   **Autoevaluación de Estándares Mínimos** (Res. 0312).
*   **Matriz de Riesgos Dinámica** (GTC 45) con cálculo automático de nivel de riesgo.
*   **Tablero de Indicadores Mínimos** de accidentalidad y enfermedad laboral.

## 🛠️ Stack Tecnológico
*   **Backend:** Node.js + Express.
*   **Base de Datos:** PostgreSQL (Integridad referencial para auditorías legales).
*   **Arquitectura:** REST API escalable.

## ⚖️ Marco Legal Integrado
El software está diseñado bajo los parámetros del Ministerio de Trabajo de Colombia para facilitar el reporte anual obligatorio.
